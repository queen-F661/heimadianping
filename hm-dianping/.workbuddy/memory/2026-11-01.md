## 黑马点评 —— 附近商铺查询（GEO）接口修复

文件：`src/main/java/com/hmdp/service/impl/ShopServiceImpl.java` → `queryShopByType`

修复的问题：
1. 编译错误「已在方法中定义变量 result」：lambda 参数与局部变量同名（lambda 参数不能遮蔽外层局部变量）。外层统一改名 `results`，lambda 参数改名 `geoResult`。
2. 方法末尾缺 return（Missing return statement）。
3. 无坐标分支返回 `Result.ok(page)` 改为 `Result.ok(page.getRecords())`，前端需要数组。
4. null 判断错对象：`results == null` 改为判断 `list == null || list.isEmpty()`。
5. 补齐业务闭环：收集 ids + distanceMap → `in("id", ids).last("ORDER BY FIELD(id,...)")` 保序查询 → 回填 `shop.setDistance()`。
6. 边界保护：`ids` 为空直接返回空列表，避免 `IN ()` SQL 语法错误。

要点备忘：
- `Shop.distance` 是 `@TableField(exist = false)` 的假字段，配合 `@Accessors(chain = true)` 可 setter 链式。
- Redis GEO `new Distance(5000)` 单位是米（5km）。
- 本机未配置 mvn 到 PATH，本项目无法命令行编译，验证靠 IDEA。
