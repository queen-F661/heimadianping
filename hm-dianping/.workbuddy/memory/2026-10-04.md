## 黑马点评 - 修复关停时 LettuceConnectionFactory destroyed 刷屏

- 现象：Ctrl+C 停项目（退出码 130）时，`pool-2-thread-1` 后台线程狂刷 `IllegalStateException: LettuceConnectionFactory was destroyed`。
- 根因：Spring 销毁 Bean 先于后台线程退出，线程仍在 while(true) 里读 Redis Stream。
- 修复（VoucherOrderServiceImpl.java）：
  - 加 `volatile boolean running` 开关 + `@PreDestroy destroy()`（置 false + shutdown 线程池）
  - `run()` 和 `handlePendingList()` 的 while(true) 均改为 while(running)
  - 两个 catch 中加 `if (!running) break;` 关停保险
- 教训：用户自己改时漏了 handlePendingList 里的 while(true)，导致死循环仍在，后由我直接补改。
- 遗留小提示：日志时间戳缺小时位（`30:12.158`），疑 application.yaml 日志 pattern `%d` 格式写错，待用户自行检查。

## 追加：修复 NOGROUP 报错（队列/消费组不存在）

- 现象：运行中刷 `NOGROUP No such key 'stream.orders' or consumer group 'g1'`。
- 根因：XREADGROUP 要求 key + group 都存在；lua 的 XADD 只建 key 不建 group；用户清过 Redis 或未手动 XGROUP CREATE。
- 修复（VoucherOrderServiceImpl.java）：
  - 新增 `initStreamGroup()`，`@PostConstruct` 时调用：key 不存在先 XADD 占位消息，再 createGroup(stream.orders, ReadOffset.latest(), "g1")，BUSYGROUP 忽略
  - handlePendingList catch 加 NOGROUP 判断，直接 break 防刷屏
- 教学点：看异常先拉到底看 `Caused by`；上次 Lettuce destroyed 已修好，这次是新问题。
