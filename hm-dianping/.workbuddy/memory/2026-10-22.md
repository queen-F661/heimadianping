## 排查 AopContext.currentProxy() 报错

- 报错：`IllegalStateException: Cannot find current proxy: Set 'exposeProxy' property on Advised to 'true'`
- 位置：`VoucherOrderServiceImpl.seckillVoucher` 第 272 行 `AopContext.currentProxy()`
- 根因：启动类 `HmDianPingApplication` 上缺少 `@EnableAspectJAutoProxy(exposeProxy = true)`，CGLIB 拦截器不会 `AopContext.setCurrentProxy(proxy)`，ThreadLocal 取出来是 null。
- 修复：启动类加注解（或 `<aop:aspectj-autoproxy expose-proxy="true"/>`）。

## 顺带发现的隐患（未修，已告知用户）

1. `VoucherOrderServiceImpl` 里新旧两套逻辑并存：Lua+Stream 异步版（VoucherOrderHandler）已写好，但 `seckillVoucher` 仍走旧版 synchronized + AopContext + 事务。
2. `opsForStream().acknowledge("s1", "g1", record.getId())` 的 key 写成了 `s1`，实际 stream key 是 `stream.orders`，会导致消息永远留在 pending-list 重复消费（两处：run() 和 handlePendingList()）。
3. `int count = query()...count()` —— MyBatis-Plus 的 count() 返回 Long，自动拆箱赋给 int。
4. `createVoucherOrder(Long)` 里 `new RedisIdWorker(stringRedisTemplate)`，RedisIdWorker 是 @Component 且类里已注入 `redisIdWorker` 字段，应直接用注入的实例。

## 加注解后的连带问题（已修）

- 现象：加 `@EnableAspectJAutoProxy(exposeProxy = true)` 后启动报 `NoClassDefFoundError: org/aspectj/lang/annotation/Pointcut`。
- 根因：pom 里没有 aspectjweaver。只用 `@Transactional` 时走 InfrastructureAdvisorAutoProxyCreator，不碰 AspectJ 类；一旦显式开启 `@EnableAspectJAutoProxy`，注册的是 `AnnotationAwareAspectJAutoProxyCreator`，它的静态初始化就要加载 `org.aspectj.lang.annotation.Pointcut`。
- 修复：pom.xml 增加 `spring-boot-starter-aop`（不带 version，由 parent 2.3.12 管理，对应 aspectjweaver 1.9.6）。本地 ~/.m2 已有 1.9.4/1.9.6，IDEA 刷新 Maven 即可离线解析。
- 环境：项目没有 mvnw，PATH 上也没有 mvn，只能靠 IDEA 的 Maven 面板刷新。
